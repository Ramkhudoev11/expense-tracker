# Expense Tracker — Personal Finance Web App

A personal finance tracking application to manage expenses, income, subscriptions, and daily routines by category.

## Features
- Expense tracking by category with date filtering
- Income and subscription tracking
- Statistics and reporting
- User registration and login (Django Auth)
- Premium tier (in development)

## Tech Stack
Python, Django, PostgreSQL, Django Auth

## Live Demo
https://expense-tracker-production-cdae.up.railway.app

## Setup
bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
